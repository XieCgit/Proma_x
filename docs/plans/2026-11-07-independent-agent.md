# 独立桌面 Agent 实施计划

**目标：**以 Proma 开源社区版为基础，建立可在 macOS Intel 上独立开发的桌面 Agent，在保持原项目许可的前提下逐步吸收官方版的可靠性思路和本地定制版中有价值的功能。

**架构：**保留上游 Bun monorepo：Electron 主应用在 `apps/electron`，通用包在 `packages/`，CLI 在 `apps/cli`。本项目使用独立的应用标识和数据命名空间；不复制生产配置、凭据或商业版编译代码。功能通过现有主进程/预加载/渲染层边界实现，并以单元测试和可控隔离测试验证。

**基线与许可：**上游 `proma-ai/Proma`，克隆时 HEAD `86d9dfb511db4c1e3ffded3b6c3e312996f50cbf`；遵守仓库现有 AGPL-3.0 许可与归属。官方商业版完整源码不可用，不能假设商业能力或接口均可复现。

**绝对边界：**本项目的开发与测试不得写入既有 `~/.proma`、`~/.proma-dev`、当前工作区或现有 App；禁止使用上游会按端口或进程名杀死其他进程的开发清理脚本。尚未配置本项目更新发布源前，禁止从官方自动下载和覆盖本项目。秘密不提交到 Git。

## 任务 1：确认安全基线并准备工具

- 审查 `apps/electron/src/main/lib/config-paths.ts`、`apps/cli/src/paths.ts`、`apps/electron/src/main/index.ts`、`apps/electron/scripts/dev-kill.ts`、`apps/electron/electron-builder.yml` 及更新器路径。
- 在仓库 `.local/` 中准备经上游 SHA-256 验证的 Bun 和隔离用 HOME、缓存及临时目录；将其加入 Git 忽略列表。安装依赖必须只写入新仓库及隔离目录。
- 保留 `upstream` 用于追踪开源上游，不配置未来用户 GitHub 仓库的 `origin`，不推送。

## 任务 2：实现并测试强隔离默认值

**候选文件：**`apps/electron/src/main/lib/config-paths.ts`、`apps/cli/src/paths.ts`、`apps/electron/src/main/index.ts`、`apps/electron/src/renderer/components/app-shell/SearchDialog.tsx`、`apps/electron/electron-builder.yml`、`apps/electron/scripts/dev-kill.ts`、相关测试。

- 编写会失败的隔离测试，验证应用和 CLI 默认不读取或创建旧配置目录；验证进程清理脚本不会杀死其他进程。
- 修改应用、CLI 和提示词中数据目录的默认命名空间；在 Electron 单实例锁之前设置独立 userData；更改打包标识和名称。
- 禁止官方自动更新源用于新项目，直到将来配置独立发布渠道；禁止开发脚本清理不属于本项目的进程或占用端口。
- 将沙箱 HOME 下的旧配置目录放入哨兵文件，通过测试验证哨兵内容和目录未变化。注意这一验证不能证明操作系统级完全沙箱隔离。

## 任务 3：优先构建可运行的 Agent 核心

- 沿用并验证开源版现有的渠道配置、Agent 会话和工具能力，不将已有功能冒称本次新增。
- 根据实际源码补足停止/失败后上下文保留及异常后运行槽释放；先写覆盖不同事件顺序的测试，避免竞态与重复消息。
- 在当前 Pi 版本与较新版本之间先做接口兼容调研；没有足够证据或测试时不强制升级全部依赖。

## 任务 4：分步实现和验证定制功能

- 根据已核实的代码接入点，设计提示词增强：主进程处理渠道与凭据、可取消与可控超时；界面保留原稿，不自动发送。
- 设计 Token 统计：仅按已记录的 usage 汇总，分别处理输入、输出和缓存字段，避免会话汇总重复计数；无 usage 时明确显示暂无数据。
- Antigravity/ACP 必须在有合法可用的传输协议、独立认证和充分测试条件下接入；不得复制来历不明的私有二进制或将占位界面宣称为已实现。
- 与官方 Gemini 等模型适配重叠的功能，应先核对上游已有实现和所用协议，再编写表驱动测试与最小兼容实现。

## 任务 5：审核、测试与交付

- 简单、相互独立的任务优先交给 `gemini-3.8-flash-high`；父会话 GPT 对每项子模型产出逐项核验代码、范围及测试后才可采纳。重要边界视需要追加 Gemini 4 审查，父会话仍需复核。
- 在独立 HOME 和缓存中运行最小相关测试、类型检查与构建；在安全隔离未核验前不启动应用。
- 如能安全启动桌面应用，按桌面验收技能检查真实入口；无法验证时如实说明。不可在测试期间接入现有账号、修改系统权限或付费请求。
- 记录已完成和未实现的能力、启动命令、许可证、数据路径与 GitHub 接入步骤；最终以实际测试结果为准。
